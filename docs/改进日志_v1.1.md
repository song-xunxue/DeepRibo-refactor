## 阶段一：多尺度CNN + 注意力LSTM

### 核心改进

#### 1. 多尺度CNN（MultiScaleCNN）
- **原始**：固定 12x1 单一卷积核
- **改进**：并行使用 6/9/12 三种尺度的卷积核，分别对应短、中、长 motif 模式
- **增强**：添加 BatchNorm、padding 对齐、1x1 卷积融合
- **输出**：全局平均池化 → 256 维特征向量

#### 2. 注意力LSTM（AttentionLSTM）
- **原始**：普通双向 GRU，无注意力机制
- **改进**：双向 LSTM + Bahdanau 注意力
- **兼容**：支持 PackedSequence 变长输入（训练器使用 pack_padded_sequence）
- **输出**：注意力加权上下文向量 → 256 维特征向量

#### 3. 特征融合
- **原始**：CNN 展平 + GRU 隐藏状态 → 直接拼接
- **改进**：CNN 全局池化 + LSTM 注意力上下文 → 各自映射到 256 维 → 拼接为 512 维

### 模型参数量
- V3 (DualComplex): ~1,668,611 参数
- V1.1 (DualComplex_V11): ~1,797,843 参数（+7.8%）

## ECO 数据集对比结果

**训练配置**: epochs=20, batch_size=256, lr=0.001, valid_size=0.05, cutoff rpkm=0.12/coverage=0.12

| 指标 | V3 (CNNRNN) | V1.1 (CNNRNN_V11) | 变化 |
|------|-------------|-------------------|------|
| Best Valid AUC | **0.991** | 0.988 | -0.003 |
| Final Train AUC | 0.995 | **0.998** | +0.003 |
| Final Train Loss | 0.132 | **0.100** | -0.032 |
| Final Valid Loss | **0.134** | 0.236 | +0.102 |
| Final Train PR | 0.751 | **0.905** | +0.154 |
| Final Valid PR | 0.710 | 0.776 | +0.066 |
| Best Epoch | 20 | 10 | 更早收敛 |

### 分析

1. **训练能力增强**：V1.1 训练 loss 更低（0.100 vs 0.132）、PR 更高（0.905 vs 0.751），说明模型拟合能力更强
2. **泛化略逊**：验证 AUC 微降 0.3%（0.991→0.988），验证 loss 从 epoch10 后持续上升（过拟合）
3. **收敛更快**：best model 在 epoch10（V3 在 epoch20），提前10轮达到最优
4. **PR 显著提升**：训练 PR 从 0.751 提升到 0.905，对正样本（真实基因）的识别精度大幅改善

### 结论

V1.1 在拟合能力和正样本识别精度上优于 V3，但泛化能力略有不足。后续优化方向：
- 增加 Dropout 比例（当前 0.3）
- 引入早停机制（patience=3）
- 减小全连接层维度
- 尝试 Label Smoothing
